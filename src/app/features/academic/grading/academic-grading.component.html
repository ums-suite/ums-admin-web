Grade Correction

The only control for changing a published grade. There is no raw edit form -- ums-core has no GET /grades/{{ '{id}' }} endpoint at all, so this correction call is also the only way to see the resulting grade. A reason is mandatory.

Reviewer on Leave?

ums-core's LeaveRequest approval chain has no delegate/escalation mechanism, and grade-related permissions have no per-request delegate routing (confirmed gaps). The interim path is temporarily granting the relevant permission to a covering staff member via Role & Permission-bundle administration, then revoking it once the absence ends.
